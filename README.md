# DermoPure (ديرمو بيور)

متجر إلكتروني ثابت (Static) للمواد الشبه صيدلانية والعناية بالبشرة، جاهز للنشر مباشرة على **GitHub Pages** — بدون أي خطوة بناء (build step) وبدون خادم خلفي.

## البنية

```
index.html    → الهيكل، الـ Header، الـ Hero، الفئات، شبكة المنتجات، جميع النوافذ المنبثقة (Modals)
style.css     → نظام التصميم (ألوان، خطوط، مكوّنات) — عيادي/صيدلاني أنيق
app.js        → كل منطق التطبيق (ES6 Module): البحث، الفلترة، السلة، الطلب، واتساب/تيليغرام
products.js   → كتالوج المنتجات (يمكنك تعديله بحرية)
config.js     → إعدادات المتجر: توكن تيليغرام، رقم واتساب، قائمة الولايات الـ58
```

## التشغيل محليًا

هذا المشروع يستخدم ES Modules (`type="module"`)، لذا يجب تشغيله عبر خادم محلي بسيط (فتح الملف مباشرة بـ `file://` لن يعمل بسبب سياسة CORS للمتصفحات):

```bash
python3 -m http.server 8000
# أو
npx serve .
```

ثم افتح `http://localhost:8000`.

## النشر على GitHub Pages

1. أنشئ مستودع (repository) جديد وارفع هذه الملفات إلى الفرع `main`.
2. في إعدادات المستودع → **Pages** → اختر المصدر `Deploy from branch` → الفرع `main` → المجلد `/root`.
3. احفظ، وسيصبح الموقع متاحًا على `https://<username>.github.io/<repo>/`.

## الإعداد قبل النشر (مهم)

### 1. صور المنتجات
الصور الحالية هي عناصر نائبة (placeholders) بألوان العلامة التجارية. استبدل الحقل `image` في `products.js` بروابط صورك الحقيقية (مربعة، 800×800 بكسل أو أكبر)، ويُفضّل رفعها داخل مجلد `assets/products/`.

### 2. تفعيل إرسال الطلبات إلى تيليغرام
1. أنشئ بوت عبر [@BotFather](https://t.me/BotFather) واحصل على `botToken`.
2. احصل على `chatId` الخاص بك عبر [@userinfobot](https://t.me/userinfobot) أو بمراسلة البوت ثم زيارة:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. في `config.js`:
   ```js
   telegram: {
     botToken: "123456789:AA...",
     chatId: "-100123456789",
     enabled: true,
   },
   ```

> ⚠️ **تنبيه أمني:** أي قيمة توضع في `config.js` تكون مرئية للجميع في كود الصفحة (view-source). توكن بوت تيليغرام يستطيع فقط إرسال رسائل لمحادثة محددة، لذا الخطر محدود، لكن للإنتاج الجاد يُفضّل تمرير الطلب عبر دالة وسيطة (Cloudflare Worker / Vercel Edge Function) تُخفي التوكن فعليًا.

### 3. رقم واتساب
غيّر `whatsapp.number` في `config.js` إلى رقمك بالصيغة الدولية بدون `+` وبدون الصفر الأول (مثال: `213555112233`).

### 4. (اختياري) Google Sheet Webhook
يمكنك أيضًا إرسال نسخة من كل طلب إلى Google Sheet عبر Apps Script Web App، بوضع رابط الـ webhook في `googleSheetWebhookUrl`.

## الميزات المُنفّذة

- بحث حي مع تنظيف المدخلات (Sanitization) ضد DOM-XSS
- فلترة حسب الفئة + ترتيب حسب السعر/الأكثر مبيعًا
- نافذة عرض سريع (Quick View) مع تبويبات: الوصف / طريقة الاستخدام / المكونات
- سلة مشتريات مع تخزين محلي (`localStorage`) وتحديث تلقائي للكمية والمجموع
- نموذج "أطلب الآن" مع تحقق من رقم الهاتف الجزائري (05/06/07 + 8 أرقام) وقائمة الولايات الـ58
- زر "الطلب عبر واتساب" يبني رابط `wa.me` ديناميكيًا يحتوي تفاصيل الطلب الكاملة
- Skeleton loaders + `loading="lazy"` على كل الصور
- تصميم متجاوب بالكامل (Mobile → Desktop) ومهيأ للعربية RTL بالكامل
- روابط خارجية آمنة (`rel="noopener noreferrer"`)
